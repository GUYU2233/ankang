# 数据集要求（供收集与标注）

> 本文件用于指导团队成员按统一标准收集、筛选、标注“跌倒风险识别”方向所需数据集。
> 数据集将用于：① 跌倒动作检测模型（实时预警）；② 跌倒风险因子提取与风险评分模型（前置预判）；③ 误报抑制与场景适应。
> 请尽量按下列要求收集，不能满足的部分请在 `data/README` 中说明偏差。

---

## 1. 数据类别与场景覆盖

### 1.1 必要场景
必须覆盖居家养老三大典型场景：

| 场景 | 重点事件 | 典型位置 |
|---|---|---|
| 客厅 | 行走、起坐、站立不稳、绊倒、前/后/侧向跌倒、沙发滑落 | 沙发、茶几、电视柜旁 |
| 卧室 | 下床、起夜、床上坠落、床边跌倒、久卧 | 床、床头、灯开关处 |
| 卫生间 | 滑倒、晕倒、长时间停留、借助扶手 | 淋浴区、马桶、洗手台 |

优先收集：卫生间滑倒、卧室下床跌倒、客厅绊倒。

### 1.2 必要事件类别（每类都尽量有）

A. 跌倒事件（正样本，必须多场景多角度）：
- 前向跌倒、后向跌倒、侧向跌倒
- 滑倒（卫生间地面）、绊倒（有障碍物）、晕倒（先晃后倒）、从床/椅/沙发坠落
- 跌倒后静止（倒地不起）与跌倒后自行爬起（两类都要）

B. 近似跌倒但非跌倒（用于降误报，必须数量足够）：
- 快速下蹲、猛然坐下、弯腰捡物、躺下、床上翻身、蹲下系鞋带
- 老人拥抱/搀扶、护工扶起倒地者、多人混叠

C. 正常日常活动（负样本，覆盖全场景）：
- 正常行走、慢走、拄拐走、走停、转身、起立、坐下、下蹲、站立聊天
- 扫地、拖地、整理衣物、开关窗帘、如厕、洗漱（可遮挡）

D. 跌倒风险行为（用于风险前置预判，重点标注）：
- 步态不稳/摇晃、拖步、明显跛行、步速明显变慢、步幅变小
- 站立时明显前倾/侧倾、频繁扶墙/扶家具
- 久坐/久卧超过 2 小时、夜间频繁离床（≥3 次/晚）
- 卫生间停留超 30 分钟、在门口/床边徘徊
- 拿高处物品时站立不稳、穿脱衣物单脚支撑过久

### 1.3 环境与成像条件
每类事件尽量覆盖：
- 光线：白天自然光、夜间灯亮、夜间红外/微光
- 角度：正常挂壁角度（俯角 15°–40°）、天花板/墙角高位安装
- 距离：近景 1–3 米、中景 3–6 米
- 画面：人物完整入画；单画面内可 1 人（主要）与 2 人（护工/家属）
- 遮挡：部分遮挡（家具遮挡 20%–40%）每个场景至少有样本

## 2. 视频文件与格式要求

| 项目 | 要求 |
|---|---|
| 容器格式 | MP4（H.264，优先） |
| 分辨率 | 不低于 1280×720（推荐 1920×1080） |
| 帧率 | ≥ 15 fps（推荐 25 fps） |
| 单段时长 | 标注视频 5 秒–3 分钟；长时风险行为可 10–60 分钟 |
| 音频 | 不要求；如包含请统一说明，默认忽略 |
| 文件命名 | `{场景}_{事件类型}_{编号}_{日期}.mp4`，如 `bedroom_fall_01_20260801.mp4` |
| 每段事件 | 一段视频只包含一个主事件（长时风险行为除外） |

## 3. 目录结构与数据清单

采用如下目录结构打包提交：

```
data/
├── README.md                     # 数据来源、采集说明、偏差说明
├── manifest.csv                  # 总清单（见第 4 节列定义）
├── videos/
│   ├── livingroom/
│   │   ├── fall/                 # 跌倒片段
│   │   ├── nearfall/             # 近似跌倒
│   │   ├── normal/               # 正常活动
│   │   └── risk_behavior/        # 跌倒风险行为
│   ├── bedroom/
│   │   ├── fall/ ... (同上)
│   └── bathroom/
│       ├── fall/ ... (同上)
├── annotations/
│   ├── action_events/            # 事件级标注 JSON，与视频同名
│   ├── skeleton/                 # （可选）骨架关键点 COCO 格式
│   └── frame_bbox/               # （可选）逐帧框标注
└── meta/
    ├── subject_info.csv          # 受试者信息（脱敏）
    ├── environment.csv           # 每段视频的成像条件
    └── sensor/                   # （可选）环境/生理传感器数据
```

`manifest.csv` 列定义（UTF-8 编码，逗号分隔）：

```
video_path, scene, event_type, action_label, subject_id, age_group, gender,
lighting, camera_angle, occlusion, resolution, fps, duration_s,
fall_start_ts, fall_end_ts, annotation_file, sensor_file, note
```

- `action_label` 取值：`fall / nearfall / normal / risk_behavior`
- `event_type` 更细，如 `forward_fall / slip_fall / sit_down_fast / walking / unstable_gait / night_wandering ...`
- `fall_start_ts / fall_end_ts`：仅 fall/nearfall 必填（秒，相对视频起点）

## 4. 标注要求

### 4.1 事件级标注（必须）
每个视频一个同名 JSON：

```json
{
  "video": "bedroom_fall_01_20260801.mp4",
  "scene": "bedroom",
  "action_label": "fall",
  "event_type": "fall_from_bed",
  "fall_start_ts": 3.2,
  "fall_end_ts": 5.1,
  "person_bbox": [320, 180, 640, 720],
  "lighting": "night_ir",
  "occlusion": "none",
  "subject": {
    "subject_id": "S01",
    "age_group": "70-79",
    "gender": "male",
    "mobility_aid": "none"
  },
  "notes": "下床后站立不稳后仰跌倒，倒地静止约 35 秒"
}
```

### 4.2 逐帧/事件框标注（推荐）
- 跌倒与近似跌倒样本，至少标注事件起始帧与结束帧的行人框（COCO bbox 格式 `[x, y, w, h]`）。
- 建议用 CVAT / X-AnyLabeling / LabelImg 标注；导出 COCO 或 YOLO 格式均可。

### 4.3 骨架关键点（可选但强烈推荐）
- 若条件允许，抽帧标注 17 点 COCO 骨架（间隔 5 帧），用于训练/验证姿态流模型。
- 如已使用公开数据集（URFD 等自带头部/骨架），无需重复标注，但需在 `data/README.md` 说明来源与许可证。

### 4.4 风险行为标注
- `risk_behavior` 类不做逐帧框，但需要事件级标签 + 起始结束时间 + 风险因子描述。
- 长视频需在 `notes` 写出风险片段的时间区间（如“01:20–05:40 久坐后站立摇晃”）。

## 5. 规模建议（最低可接受量）

| 类别 | 最低数量 | 建议数量 | 说明 |
|---|---|---|---|
| 跌倒片段 | 60 段 | 150–300 段 | 三种场景、多类型分布，受试者 ≥ 10 人 |
| 近似跌倒 | 40 段 | 100 段 | 用于误报抑制，必须足够 |
| 正常活动 | 2 小时 | 8–10 小时 | 三种场景均匀分布 |
| 风险行为 | 30 段/类 | 60 段/类 | 步行不稳、夜间离床、久坐、卫生间停留 |
| 受试者 | ≥ 10 人 | 20 人以上 | 覆盖 60/70/80 岁以上年龄组，男女均衡 |

说明：公开数据集（见第 7 节）可计入以上数量，但需补充自采数据覆盖卫生间、夜间红外等居家特有场景。

---

## 6. 隐私与合规

- 受试者需签署知情同意书；无法取得时，人脸必须打码/模糊处理后交付。
- 元数据不包含姓名、电话、住址等个人身份信息，仅保留 `subject_id`。
- 视频可用于算法研发、论文与竞赛演示场景，请确认使用范围。

---

## 7. 建议使用的公开数据集（可先收集）

| 数据集 | 类型 | 特点 |
|---|---|---|
| UR Fall Detection | RGB+Depth | 30 次跌倒，卧室/客厅模拟，含骨架 |
| Le2i Fall Detection | RGB | 家宅场景，多房间、多光照 |
| UP-Fall Detection | RGB+传感器 | 11 类动作 + 6 类跌倒 |
| TST Fall Detection | 手机/监控 | 8 种视频示例 |
| Multiple Cameras Fall Dataset | 多视角 | 适合多角度适应 |
| COCO / MPII | 骨架 | 用于姿态估计预训练 |

> 注意：公开数据集的居家场景、老年人主体覆盖有限，务必用自采数据补齐卫生间滑倒、卧室下床跌倒、夜间红外三大盲区。
