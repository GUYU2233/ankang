# 研究报告大纲（供撰写最终参赛报告）

> 题目：智护安康：面向智慧养老的老年人跌倒风险识别与智能预警系统

## 一、题目背景与意义

- 老龄化现状、居家跌倒风险数据。
- 现状痛点：事后响应为主，缺乏前置预判。
- 选题意义：前置预判—过程识别—分级预警闭环。

## 二、研究内容与技术路线

- 方向选择：跌倒风险（单选）。
- 总体思路：萤石开放平台 + 海康兼容 + 多模态 AI。
- 技术路线图：设备接入 → 取流 → 骨架/行为 AI → 风险评分 → 分级预警 → 处置闭环。

## 三、系统设计与实现

- 架构图与模块划分。
- 设备接入层（萤石/海康/ONVIF/模拟）。
- 核心算法：跌倒检测与风险因子提取。
- 分级预警与适老化交互。

## 四、实验与结果

- 数据集说明（自建场景 + 公开数据集）。
- 测评指标：准确率、召回率、误报率、响应时延。
- 结果表格与截图。

## 五、核心创新点

- 前置预判：跌倒风险因子滑动窗口评分。
- 全流程闭环：跌倒前、中、后一体化。
- 厂商兼容：萤石+海康双协议适配。

## 六、应用价值与落地路径

- 居家养老三大场景落地与成本分析。
- 适老化交互与隐私合规。

## 七、总结与展望

- 局限：无真机联调、训练数据有限。
- 展望：真实传感器融合与社区联动。
