# 系统设计文档：智护安康

## 1. 总体架构

```
应用层    家属/护工 Web 端 · 数据看板 · 告警推送
业务层    Spring? → 当前为 FastAPI 业务服务（backend）
         设备管理 / 告警中心 / 风险档案 / 实时画面 / 统计大屏
算法层    AI 推理引擎（ai-engine）YOLOv8-Pose 骨架 + 跌倒启发式 + 风险因子评分 + 模拟推理兜底
数据流层  流媒体取流（模拟流/本地视频/RTSP）→ 抽帧 → AI 推理 → 评分 → 分级预警 → WebSocket 推送
设备层    萤石开放平台 OpenAPI / 海康 HCNetSDK-ISAPI-RTSP / ONVIF-RTSP / 模拟设备
存储层    MySQL（业务） / Redis（预留） / MinIO（预留证据留存） / SQLite（本地开发）
```

## 2. 核心业务流程

1. 设备注册：手动登记或从萤石开放平台/海康桥接同步。
2. 取流：模拟流本地生成、本地视频文件、RTSP 直连（海康/ONVIF 兼容）。
3. 抽帧推理：后端定时抽帧，调用 ai-engine `/v1/infer`。
4. 风险评分：滑动窗口对风险因子评分平滑，输出 0–1 分。
5. 分级预警：绿/黄/橙/红四级；连续多帧确认 + 冷却时间抑制误报。
6. 事件闭环：生成告警与跌倒事件 → WebSocket 推送 → 家属确认处置 → 归档。

## 3. 模块划分

| 模块 | 位置 | 职责 |
|---|---|---|
| 设备接入适配层 | backend/app/core | EzvizAdapter、HikvisionAdapter、OnvifRtspAdapter、SimCamera |
| 流媒体取流 | backend/app/core/stream_service.py | 帧获取与 JPEG 编码 |
| 风险引擎 | backend/app/core/risk_engine.py | 滑动窗口评分、级别映射 |
| 预警引擎 | backend/app/core/alert_engine.py | 告警生成、误报抑制、事件归档 |
| AI 引擎 | ai-engine/app | 模拟推理 + 真实姿态推理 |
| 业务 API | backend/app/api | devices/residents/alerts/streams/dashboard |
| WebSocket | backend/app/ws | 告警实时推送 |
| 前端 | frontend/src | Vue3 + Element Plus 五张页面 |

## 5. 接口设计

- `GET /api/v1/health` 健康检查
- `GET/POST/PUT/DELETE /api/v1/devices` 设备管理
- `POST /api/v1/devices/sync` 同步萤石云设备
- `GET /api/v1/devices/{id}/live` 获取直播地址
- `GET/POST/PUT/DELETE /api/v1/residents` 老人档案
- `GET /api/v1/alerts` 告警列表
- `POST /api/v1/alerts/{id}/ack` 告警确认
- `GET /api/v1/streams/{device_id}/frame.jpg` 预览帧
- `GET /api/v1/streams/{device_id}/meta` 模拟流元数据
- `GET /api/v1/dashboard/stats` 看板统计
- `WS /ws/alerts` 告警实时推送
- `POST /v1/infer`（ai-engine）图片推理

## 6. 萤石开放平台接入说明

- 使用开放平台 OpenAPI（open.ys7.com）：`/api/lapp/token/get`、`/api/lapp/device/list`、
  `/api/lapp/device/status/get`、`/api/lapp/live/address/get`、`/api/lapp/device/capture`。
- 在 backend/.env 配置 `EZVIZ_APP_KEY` 与 `EZVIZ_APP_SECRET` 后，`POST /api/v1/devices/sync`
  会拉取账号下设备并入库。
- 真机取流地址为 ezopen/hls 协议，由流媒体层统一转封装后供前端与 AI 消费。

## 7. 海康威视兼容说明

- 无真机时通过 `DeviceCreate` 手工登记 `vendor=hikvision` + `access_url=rtsp://...`，系统走 RTSP 取流。
- 预留 HCNetSDK 桥接服务（`HIKVISION_NET_SDK_BRIDGE`）用于设备发现、登录、事件布防、抓图。
- 预留 ISAPI 配置通道，用于设备参数对齐。
- 目标：海康 IPC/NVR 在无 SDK 环境下至少通过 RTSP/ONVIF 完全可用，有 SDK 桥接后能力完整对齐。
