# 技术开发文档

## 1. 关键技术路线

- 设备接入：适配层工厂 `DeviceAdapterFactory` 统一萤石/海康/ONVIF/模拟四类来源，业务层不感知厂商差异。
- 取流与抽帧：`StreamService` 提供帧获取与 JPEG 编码；真实 RTSP 用 OpenCV `VideoCapture`；模拟流由 `SimCamera` 状态机生成。
- AI 推理：`ai-engine` 优先加载 YOLOv8-Pose；不可用时返回模拟推理，保证闭环。后续接入数据集训练的 ST-GCN/TCN 将替换 `RealRuntime._fall_by_keypoints`。
- 风险评分：`RiskEngine` 按“老人+设备”维度维护滑动窗口，对 AI 输出风险分做近邻平滑。
- 分级预警：`AlertEngine` 输出绿/黄/橙/红四级；连续多帧确认 + 冷却时间用于误报抑制。
- 实时推送：后端 WebSocket `/ws/alerts`，前端 Dashboard 监听并弹出通知。

## 2. 核心数据结构

- `AIInferResponse`：person_count、fall_detected、fall_prob、nearfall_prob、gait_unsteadiness、fall_type、risk_factors[]、risk_score、level、frame_ms、mock。
- `RiskResult`：score、level、factors、events、trigger_reason（如“步态不稳(0.82) + 卫生间停留超时”）。
- `RiskFactor`：key、label、value、unit、normal_range。
- `FramePacket`：device_id、frame、meta、captured_at。

## 3. 萤石开放平台 SDK 对接细节

约定统一走 HTTP OpenAPI，保证 Python 技术栈可运行：

| 能力 | 接口 | 说明 |
|---|---|---|
| 获取 accessToken | `POST /api/lapp/token/get` | appKey + appSecret 换 token，有效期前 60 秒自动续期 |
| 设备列表 | `POST /api/lapp/device/list` | 分页拉取 |
| 设备状态 | `POST /api/lapp/device/status/get` | 在线/离线 |
| 直播地址 | `POST /api/lapp/live/address/get` | 获取 ezopen/hls 地址 |
| 抓拍 | `POST /api/lapp/device/capture` | 获取图片地址并下载 |
| 告警订阅 | 开放平台消息推送服务 | 框架已留订阅位，真机联调时接入 |

## 4. 海康威视兼容细节

- RTSP 地址规范：`rtsp://{user}:{pwd}@{host}:{port}/Streaming/Channels/{channel}{stream}01`
  （主码流 stream=0，子码流 stream=1）。
- `HikvisionAdapter.build_rtsp_url()` 按上述规范生成。
- `HIKVISION_NET_SDK_BRIDGE` 预留 HCNetSDK JNA/桥接服务，用于设备发现、布防回调与抓拍。

## 5. AI 算法接入点

- 骨架估计：`RealRuntime._load_model()` 加载 `models/yolov8n-pose.pt`。
- 跌倒判定：现网 2 类 TCN ONNX 的 softmax `probs[1]` 仅作为 `fall_prob`；窗口未满时不触发跌倒。
- 前置风险头：`HeuristicPoseRiskHead` 独立输出 `nearfall_prob` 与 `gait_unsteadiness`（0-1）。近跌来自未完成跌倒的姿态线索（髋部下沉后回升、下蹲、快速坐下、站立踉跄），**不会**置位 `fall_detected`。步态由短时缓冲上的躯干倾斜方差、踝轨迹长度、躯干抖动合成。
- 4 类标签 `fall / nearfall / risk_behavior / normal` 已接入训练入口（`--classes multiclass --model prefall`）；暂不重训现网 ONNX，训练头接口见 `training.models.PrefallRiskHead`。
- 风险融合：`nearfall_prob` 作为 kinematic 因子进入 `FACTOR_SPECS`；高近跌升黄/橙但不抬到跌倒红档。`RiskResult.trigger_reason` 随告警 `detail_json` 与 WebSocket 下发。

## 6. 扩展指南

- 新增设备厂商：实现 `DeviceAdapter`，在 `DeviceAdapterFactory.register` 注册即可。
- 新增风险因子：在 `RiskFactor.key` 增补，并在 `ai-engine` 与 `AlertEngine` 中扩展展示。
- 新增告警渠道：在 `NotificationLog` 增补 channel，并在 `AlertEngine._emit` 中增加推送逻辑。
