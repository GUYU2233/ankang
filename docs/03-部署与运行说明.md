# 部署与运行说明

## 1. 环境要求

- Python 3.11+（本地开发）
- Node.js 20+（前端开发）
- Docker 24+ 与 Docker Compose v2（推荐部署）
- 无 Docker、无摄像头时系统自动使用内置模拟流，可完整演示业务闭环

## 2. 本地开发运行（Windows PowerShell）

### 2.1 后端

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py
```

- 服务地址：http://127.0.0.1:8000/docs
- 首次启动自动创建 SQLite 数据库与 2 路模拟设备

### 2.2 AI 推理引擎

```powershell
cd ai-engine
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8100
```

- 服务地址：http://127.0.0.1:8100/docs
- 未安装/未下载姿态模型时自动退回模拟推理，不影响闭环

### 2.3 前端

```powershell
cd frontend
npm install
npm run dev
```

- 访问 http://127.0.0.1:5173
- Vite 已配置 `/api` 与 `/ws` 代理到后端 8000 端口

## 3. Docker 部署

```powershell
cd deploy
docker compose up -d --build
```

- 前端：http://localhost:8080
- 后端 Docs：http://localhost:8000/docs
- AI 引擎：http://localhost:8100/docs
- 部署时后端自动使用 MySQL，emqx、ZLMediaKit、Redis 一并启动

## 4. 萤石开放平台实名联调

1. 注册并认证萤石开放平台（open.ys7.com），创建应用获取 `appKey/appSecret`。
2. 编辑 `backend/.env`：

   ```
   EZVIZ_APP_KEY=你的appKey
   EZVIZ_APP_SECRET=你的appSecret
   ```

3. 重启后端，调用 `POST /api/v1/devices/sync` 或在设备接入页点击“同步萤石云设备”。
4. 真实设备取流地址经 `GET /api/v1/devices/{id}/live` 获取，前端展示与 AI 推理按需切换。

## 5. 海康设备接入（无真机方案）

1. 确认海康 IPC/NVR 已启用 RTSP 服务并知晓账号密码。
2. 在后端设备管理页或 API 手工登记：
   - `vendor`: `hikvision`
   - `access_url`: `rtsp://admin:密码@设备IP:554/Streaming/Channels/101`
3. 系统自动通过 RTSP 取流；如已有 HCNetSDK 桥接服务，可配置 `HIKVISION_NET_SDK_BRIDGE` 地址。

## 6. 生成模拟测试视频（可选）

```powershell
python tools/rtsp_simulator.py --out data/sim_videos/livingroom_fall.mp4 --seconds 30
```

生成的 MP4 可按本地视频接入（设备 `access_url` 填路径）。

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 前端页面“后端服务离线” | 检查 8000 端口是否启动；检查 Vite 代理 |
| AI 引擎不可用 | 后端自动模拟兜底；也可单独启动 ai-engine |
| 收不到 WebSocket 告警 | 确认部署时 `/ws` 代理已配置 upgrade 头 |
| SQLite 并发写入报错 | 本地开发单进程可运行；生产请用 MySQL |
